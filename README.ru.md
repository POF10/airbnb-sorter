# Airbnb Sorter

[English](README.md) · **Русский**

Userscript для Tampermonkey, который добавляет в поиск Airbnb то, чего там нет: **сортировку всей выдачи по цене**. Airbnb показывает не больше 270 объявлений на поиск и не умеет сортировать их по цене. Скрипт собирает выдачу целиком (для Риги на выходные это ~1 300 объявлений) и открывает её поверх страницы в привычном виде: карточки с фото, карта с ценниками, сортировка по цене, рейтингу и числу отзывов.

Интерфейс на русском на русскоязычных страницах Airbnb, иначе на английском.

## Возможности

- **Вся выдача, а не 270 объявлений.** Поиск делится на ценовые диапазоны, пока каждый не влезет в лимит Airbnb, и собирается полностью.
- **Сортировка:** цена по убыванию (по умолчанию) и по возрастанию, рейтинг, число отзывов.
- **Карта** с ценниками, как у Airbnb: наведение на карточку подсвечивает маркер, клик по маркеру открывает мини-карточку. Фильтр «Только в области карты».
- **Карточки как на Airbnb:** карусель фото, значок «Guest favorite», рейтинг, скидка с зачёркнутой старой ценой и «≈ € за ночь».
- **Учитываются все ваши фильтры:** даты, гости, тип жилья, спальни, удобства, ценовой диапазон, область карты. Работает на www.airbnb.com и на языковых версиях (ru.airbnb.com, lv.airbnb.com, airbnb.co.uk, …).
- **Кэш последнего сбора:** повторное открытие того же поиска мгновенно, «⟳ Обновить» собирает заново.
- **Бережно к Airbnb:** три запроса одновременно, паузы между ними, автоматическая остановка при первых признаках блокировки и лимит на число запросов.

## Установка

По шагам, без технических знаний. Занимает пару минут.

1. **Установите Tampermonkey**, бесплатное расширение браузера, которое запускает пользовательские скрипты. Откройте [tampermonkey.net](https://www.tampermonkey.net/) и нажмите кнопку для своего браузера (Chrome, Edge, Firefox, Opera, Safari). Подтвердите установку в окне браузера.
2. **Разрешите пользовательские скрипты** (только Chrome и Edge; Chrome требует этого от всех расширений со скриптами):
   1. Наберите в адресной строке `chrome://extensions` (в Edge — `edge://extensions`) и нажмите Enter.
   2. Найдите Tampermonkey и нажмите **«Подробнее»**.
   3. Включите переключатель **«Разрешить пользовательские скрипты»** (Allow User Scripts). Если такого переключателя нет, у вас старая версия браузера: включите вместо этого **«Режим разработчика»** в правом верхнем углу той же страницы.
3. **Установите скрипт.** Откройте ссылку:

   **[Установить Airbnb Sorter](https://github.com/POF10/airbnb-sorter/releases/latest/download/airbnb-sorter.user.js)**

   Tampermonkey откроет страницу с описанием скрипта. Нажмите **«Установить»**. Всё: скрипт установлен, а обновления Tampermonkey будет подтягивать сам.

Если по ссылке открывается просто текст, а не страница установки, значит, шаг 2 не выполнен или Tampermonkey выключен. Страница со всеми версиями — [здесь](https://github.com/POF10/airbnb-sorter/releases).

## Использование

1. Откройте поиск жилья на Airbnb и настройте всё как обычно: даты, гостей, фильтры. Если вы двигали карту с включённым «Искать при перемещении карты», соберётся только видимая область.
2. Нажмите кнопку **«↕ Сортировать все»** в правом нижнем углу.
3. Дождитесь конца сбора. Для ~1 300 объявлений это около 45 секунд и 60 МБ трафика (Airbnb отдаёт страницы поиска целиком, по ~750 КБ каждая). Во время сбора видно, сколько уже собрано.

Дальше всё как в Airbnb: карточки открываются в новой вкладке с вашими датами, карту можно двигать и приближать, «Только в области карты» оставляет в списке то, что сейчас видно на карте. Esc или × закрывают слой.

Что означают надписи в шапке:

- **«Собрано 1 361 из ~1 258»** — сколько объявлений собрано и сколько Airbnb оценивает по своей гистограмме цен. Оценка приблизительная, собранное число может быть и больше неё.
- **⚠** — сбор неполный; причина видна при наведении: отменён, Airbnb начал блокировать запросы, часть страниц не загрузилась.
- **«· 12 мин назад»** — результат показан из кэша. «⟳ Обновить» соберёт заново.
- **«≈ €74/ночь»** — итоговая цена за поездку (со сборами), делённая на число ночей. В поиске без дат Airbnb показывает у каждого объявления цену за его собственные даты, обычно 5 ночей; ссылка с карточки ведёт на эти же даты.

«Отмена» во время сбора (как и закрытие слоя) показывает то, что уже собрано; такой неполный результат в кэш не попадает.

## Как это работает

Airbnb отдаёт на один поиск не больше 15 страниц по 18 объявлений, зато принимает фильтр цены за ночь `price_min`/`price_max`. Скрипт запрашивает первую страницу поиска; если страниц 15 (диапазон переполнен), делит ценовой диапазон пополам и повторяет для каждой половины, пока диапазоны не станут достаточно узкими. Границы соседних диапазонов пересекаются, чтобы не потерять объявления ровно на границе, а дубли убираются по id. Для ~1 300 объявлений выходит примерно 8 диапазонов и 90 запросов.

Данные берутся из JSON, который Airbnb встраивает в HTML страницы поиска (тот же, из которого рисуется страница), без обращения к внутреннему API. Результат нормализуется в единый формат, и модуль просмотра уже ничего не знает об Airbnb.

Сбор останавливается сам, если Airbnb начинает блокировать запросы (страница без данных, HTTP 401/403, три сбоя подряд) или если запросов становится подозрительно много (не больше `max(300, 4 × ожидаемое число страниц)`). Ошибки 429/5xx повторяются с паузами 2, 4 и 8 с.

Если вы задали ценовой диапазон сами, скрипт делит только его и в том же режиме, что и вы: за ночь или, при включённом показе итоговой цены, за всю поездку.

Подробный дизайн, включая то, что проверялось на живом Airbnb, — в [docs/superpowers/specs/2026-09-28-airbnb-sorter-design.md](docs/superpowers/specs/2026-09-28-airbnb-sorter-design.md).

## Ограничения и риски

- Только поиск жилья (`/s/…/homes`); впечатления и услуги не поддерживаются.
- Выдача Airbnb персонализирована и может меняться прямо во время сбора, поэтому единичные объявления могут потеряться.
- Скрипт зависит от структуры страниц Airbnb. Когда Airbnb её поменяет, сбор упадёт с сообщением вида «Не удалось собрать выдачу: no …», где после «no» указан путь, который перестал находиться, — это подсказка, что чинить в `src/extract.js`.
- Пользовательское соглашение Airbnb запрещает автоматический сбор данных. Скрипт работает в вашей сессии, с паузами и лимитами, но риск ограничений для аккаунта не нулевой. Используйте на свой страх и риск.

## Разработка

```bash
npm install
npm test        # юнит-тесты (node:test), сборщик тестируется на синтетическом Airbnb
npm run dev     # стенд интерфейса на синтетических данных: http://localhost:8000/  (?lang=ru — русский)
npm run build   # dist/airbnb-sorter.user.js и dist/airbnb-sorter.inject.js
```

`dist/airbnb-sorter.inject.js` — та же программа без Tampermonkey: выполните его содержимое в консоли на странице поиска Airbnb, и появится та же кнопка. Удобно для отладки; кэш в этом режиме хранится в localStorage.

Структура:

| Файл | Ответственность |
|---|---|
| `src/extract.js` | HTML страницы поиска → результаты, курсоры страниц, гистограмма цен |
| `src/normalize.js` | объявление Airbnb → единый формат `Listing` |
| `src/price.js` | разбор строк цены («€1,234», «1 234 €», «CHF 1'234») |
| `src/search-url.js` | URL поиска: чистка, ценовые диапазоны, страницы |
| `src/collector.js` | деление по цене, очередь запросов, повторы, остановка, отмена |
| `src/cache.js` | кэш последнего сбора |
| `src/i18n.js` | тексты интерфейса (английский, русский) |
| `src/viewer/` | слой в Shadow DOM: карточки, список, карта (Leaflet + OpenStreetMap), сортировка |
| `src/launcher.js`, `src/main.js` | кнопка на странице и связка всего вместе |
| `src/userscript.js`, `dev/inject.js` | точки входа для Tampermonkey и для запуска без него |

Выпуск версии: поднять `version` в `package.json`, выполнить `npm run build` и приложить `dist/airbnb-sorter.user.js` к релизу на GitHub с именем `v<версия>`. Установленные копии обновятся сами с последнего релиза.

Требуется Node.js 22+.
