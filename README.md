# Airbnb Sorter

Userscript для Tampermonkey. Airbnb показывает в поиске не больше 270 объявлений (15 страниц), а этот скрипт собирает **всю** выдачу и открывает её полноэкранным слоем поверх страницы: карточки с фото, карта, сортировка по цене (↓/↑), рейтингу и числу отзывов.

## Установка

1. Поставить расширение [Tampermonkey](https://www.tampermonkey.net/) в Chrome.
2. Открыть `chrome://extensions`, у Tampermonkey нажать «Подробнее» и включить **Allow User Scripts** (Chrome требует этого от расширений с userscript'ами).
3. Собрать скрипт: `npm install && npm run build`.
4. В Tampermonkey: «Панель управления» → вкладка «+» (новый скрипт) → удалить шаблон, вставить всё содержимое `dist/airbnb-sorter.user.js` → Ctrl+S. Можно и через «Утилиты» → «Импорт из файла», если ваша версия Tampermonkey принимает `.user.js`.

Чтобы обновить скрипт, выполните `npm run build` и замените текст скрипта в редакторе Tampermonkey.

## Использование

1. Откройте поиск на airbnb.com (подойдут и языковые версии: lv.airbnb.com, ru.airbnb.com и другие). Выставите даты, гостей и любые фильтры: скрипт собирает выдачу по текущему адресу страницы, поэтому все фильтры учитываются. Если вы двигали карту с включённым «Искать при перемещении карты», соберётся только видимая область.
2. Нажмите «↕ Сортировать все» справа внизу.
3. Дождитесь конца сбора. Для Риги на 3 ночи это около 1 360 объявлений: примерно 45 с и 60 МБ трафика. Кнопка «Отмена» (и закрытие слоя через Esc или ×) останавливает сбор и показывает то, что уже собрано. Такой неполный результат не сохраняется, и следующее нажатие начнёт сбор заново.

Последний сбор сохраняется. Если снова нажать кнопку на том же поиске, результаты откроются сразу, а «⟳ Обновить» соберёт всё заново. Значок ⚠ в шапке означает, что сбор неполный; причина видна при наведении. «Только в области карты» оставляет в списке только объявления, которые видны на карте.

«≈ €74/ночь» — это итоговая цена за поездку, делённая на число ночей, так что в неё входят сборы. В поиске без дат Airbnb показывает у каждого объявления цену за его собственные даты (обычно 5 ночей), и ссылка с карточки ведёт на эти же даты.

## Как это работает

Airbnb отдаёт на один поиск не больше 15 страниц по 18 объявлений. Скрипт делит поиск на ценовые диапазоны через фильтр `price_min`/`price_max`, пока каждый диапазон не уложится в этот лимит, и собирает все страницы каждого диапазона. Запросы идут по три одновременно, с паузами между ними. Подробности — в `docs/superpowers/specs/2026-09-28-airbnb-sorter-design.md`.

Сбор останавливается сам, если Airbnb начинает блокировать запросы (капча, стена логина, HTTP 401/403, три сбоя подряд) или если запросов становится подозрительно много (не больше `max(300, 4 × ожидаемое число страниц)`).

## Разработка

- `npm test` — юнит-тесты (`node:test`).
- `npm run dev` — стенд интерфейса на синтетических данных (1 300 объявлений): http://localhost:8000/.
- `npm run build` — собирает два файла:
  - `dist/airbnb-sorter.user.js` — для Tampermonkey;
  - `dist/airbnb-sorter.inject.js` — для запуска без Tampermonkey: выполните его содержимое в консоли на странице поиска Airbnb, кэш тогда хранится в localStorage.

## Ограничения

- Работает только с поиском жилья (`/s/…/homes`).
- Выдача Airbnb персонализирована и может меняться прямо во время сбора, поэтому несколько объявлений могут потеряться. «~N» в шапке — это оценка Airbnb по гистограмме цен, и собранное число может быть немного больше неё.
- Пользовательское соглашение Airbnb запрещает автоматический сбор данных. Скрипт работает в вашей сессии и делает паузы между запросами, но риск ограничений для аккаунта всё равно есть.

## Если что-то не так

- **Tampermonkey не устанавливает скрипт из-за хэша** (суффикс `#sha256=…` у `@require`/`@resource`): уберите этот суффикс в `src/header.txt` и пересоберите.
- **«Не удалось собрать выдачу: нет …»** — Airbnb поменял структуру страницы. Путь в сообщении подскажет, что чинить в `src/extract.js`.
- **⚠ «Airbnb начал блокировать запросы»** — подождите и попробуйте позже.
